# Cosmic2048
Sebuah perpaduan epik antara game puzzle klasik 2048 dengan keindahan estetika luar angkasa yang memukau. Rasakan sensasi menjadi arsitek alam semesta, di mana setiap geseran jari Anda dapat menciptakan, menggabungkan, dan mengevolusikan materi kosmik dari sebutir debu bintang hingga menjadi entitas dewa penguasa galaksi!
